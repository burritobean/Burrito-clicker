# Burrito Clicker

A browser-based incremental clicker game built around growing your own burrito empire.

## About

Burrito Clicker is a lightweight idle game built with HTML, CSS, and JavaScript. Click to earn burritos, purchase upgrades, increase automatic production, and unlock achievements as you progress.

## Features

* **Clicking System** — Earn burritos with every click.
* **Click Upgrades** — Increase the amount earned per click.
* **Auto Production** — Generate burritos automatically over time.
* **Achievements** — Complete milestones and earn bonus rewards.
* **Automatic Saving** — Preserve progress using browser local storage.
* **Dark Interface** — A minimal dark theme with green and lime accents.
